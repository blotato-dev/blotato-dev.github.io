# Blotato Notes

Blotato is a social media API plus MCP server, sold on the idea that your agent posts for you instead of you opening nine apps.

**Read the full page:** https://blotato-dev.github.io/

This is a good fit if you already run an agent or an automation stack and want publishing to be one more tool call rather than a browser tab. It is a poor fit if nobody on your team has ever written an n8n scenario or configured an MCP server, because the interface you are paying for is machine-shaped by design. People who want a calendar, a queue and a human to press approve are describing Supapush, not this. The caveat is dependency: routing distribution through an agent means an agent failure becomes a publishing failure.
